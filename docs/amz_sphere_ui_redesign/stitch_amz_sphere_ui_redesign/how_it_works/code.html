Transactional Outbox & Event Sourcing

CORE RELIABILITY

To eliminate race conditions, phantom overwrites, and rate-limit drops, AmzSphere treats Amazon's SP-API not as a direct HTTP target, but as an asynchronous event sink. All mutations are first written inside an ACID transaction to our Postgres Outbox table.

Decoupled UI Responsiveness

UI triggers return in <10ms. Bulk updates are queued safely across 64 Celery workers regardless of external SP-API congestion.

Zero Dual-Write Failures

If Amazon throws a 503 or network socket times out, the message never drops. Outbox state persists and retries with jitter.

Mathematical Floor Enforcers

GUARDRAIL LOGIC

Automated pricing algorithms frequently trigger catastrophic “race-to-the-bottom” spirals during competitive price-matching wars. The AmzSphere Sentinel halts downward pricing whenever net unit margins threaten to cross platform thresholds.

Human-in-the-Loop (HITL) Gatekeeper

GOVERNANCE

Catalog attributes, title revisions, and wholesale volume tiers have irreversible consumer-facing impact. AmzSphere divides operational tasks into two distinct trust tiers: Autonomous & Supervised.

Autonomous Class A

Real-time micro-repricing adjustments within safe margins (±$0.50) dispatch automatically with dry-run logs.

Supervised Class B

B2B bulk bids, title alterations, parent-child variation edits, and inventory write-offs mandate 1-click human approval.
